💘 Exotica Kenya – Backend

Welcome to the Exotica Kenya backend — the engine powering our next-gen Kenyan online dating experience.
We’re here to connect people, spark conversations, and maybe… help a few lonely hearts find some sugar. 😏
⚙️ Installation

Clone the repository

🛠️ Tech Stack

Backend: Node.js + Express.js

Database: MongoDB

Authentication: JWT (JSON Web Tokens)

Messaging: Real-time chat API endpoints
